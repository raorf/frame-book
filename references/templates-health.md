# 健康模板

## 模板1：能量管理计划
- **适用场景**：识别个人每日能量高峰与低谷，合理安排高耗能与低耗能任务，避免持续疲劳
- **核心步骤**：
  1. 连续记录三天能量波动，每小时标注精力水平（1-5分）及当时活动内容 (预估每天5分钟)
  2. 分析记录，识别个人能量高峰时段、低谷时段和平稳时段 (预估15分钟)
  3. 将高认知负荷任务安排在高峰时段，低耗能事务集中在低谷时段 (预估10分钟)
  4. 在低谷时段设计恢复策略，如10分钟散步、小憩或深呼吸练习 (预估5分钟)
- **完成标准**：形成一份个人能量地图与对应的日程安排策略，可日常参照执行

## 模板2：运动计划制定
- **适用场景**：为不同体能基础的人制定循序渐进的运动计划，兼顾进步与恢复
- **核心步骤**：
  1. 评估当前体能基础与健康状况，确定运动目标和禁忌事项 (预估15分钟)
  2. 制定每周训练安排，包含力量、有氧、柔韧性训练及至少2个休息日 (预估20分钟)
  3. 设定渐进超负荷方案，每两周提升训练量5-10%（重量、次数或时长） (预估10分钟)
  4. 建立训练记录表，追踪每次训练的完成情况、感受和身体反馈 (预估每次5分钟)
  5. 每四周评估一次进展，根据身体反应调整训练强度和内容 (预估20分钟)
- **完成标准**：产出可执行的四周运动计划，含训练日安排、进阶策略和恢复机制

## 模板3：作息调整方案
- **适用场景**：需要逐步调整睡眠节律，如从晚睡晚起过渡到早睡早起
- **核心步骤**：
  1. 记录当前作息基线，包括入睡时间、起床时间和实际睡眠时长 (预估3天每天2分钟)
  2. 设定目标作息时间，制定每3天提前15分钟的渐进调整计划 (预估10分钟)
  3. 设计睡前30分钟降温仪式，关闭屏幕、调暗灯光、做放松活动 (预估每晚30分钟)
  4. 固定起床时间（含周末），用光照和晨间活动帮助建立新节律 (预估晨间15分钟)
- **完成标准**：形成2-3周的渐进调整时间表，含每日目标入睡/起床时间和配套仪式

## 模板4：压力释放清单
- **适用场景**：在日常高压或突发焦虑时，快速选取适合当前时间窗口的释放方法
- **核心步骤**：
  1. 梳理个人压力源清单，按工作、关系、健康、财务分类并标注压力等级 (预估15分钟)
  2. 建立分时释放工具箱：1分钟级（深呼吸、握拳放松）、5分钟级（拉伸、散步）、15分钟级（冥想、书写） (预估20分钟)
  3. 为每类压力源匹配首选释放方法，并准备备选方案 (预估10分钟)
  4. 将清单放在随手可取处，设定每日定时自检压力水平的提醒 (预估5分钟)
- **完成标准**：形成一份分时、分类的压力释放清单，可在不同场景下快速调用

## 模板5：习惯养成路径
- **适用场景**：建立新习惯或替换旧习惯，利用触发-行动-奖励循环提高坚持率
- **核心步骤**：
  1. 明确目标习惯并拆解为最小可执行版本，如"每天阅读"拆为"每天读2页" (预估10分钟)
  2. 锚定现有行为作为触发器，如"刷完牙后立即做5个深蹲" (预估10分钟)
  3. 设计即时奖励，完成行为后给自己一个小而有意义的正反馈 (预估10分钟)
  4. 建立21天追踪表，每日打卡记录完成情况和执行感受 (预估每天1分钟)
  5. 在第7天和第21天复盘，评估习惯稳定度并决定是否升级难度 (预估每次15分钟)
- **完成标准**：形成完整的触发-行动-奖励方案和追踪机制，连续21天可执行可衡量
