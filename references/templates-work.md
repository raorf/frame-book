# 职场模板

## 模板1：OKR目标拆解
- **适用场景**：将季度OKR转化为可执行的周计划，确保目标层层落地、进度可追踪
- **核心步骤**：
  1. 复盘上季度OKR完成情况，标注未达标项与遗留问题（20分钟）
  2. 拆解本季度OKR为月度里程碑，每个KR至少对应2-3个关键动作（30分钟）
  3. 将月度里程碑进一步分解为周任务，明确每周交付物和验收标准（25分钟）
  4. 与上级对齐，确认优先级和资源支持，修订不合理项（20分钟）
  5. 将确认后的任务录入任务管理工具，设置截止日期和提醒（15分钟）
- **完成标准**：每个KR都有可量化的周级任务卡，上级确认无异议，任务已录入工具并设置提醒

## 模板2：项目里程碑规划
- **适用场景**：中大型项目的阶段划分，明确各节点交付物、负责人和风险预案
- **核心步骤**：
  1. 定义项目终极目标和成功标准，梳理项目全貌（15分钟）
  2. 划分3—5个关键阶段，为每个阶段命名并标注起止时间（20分钟）
  3. 为每个阶段指定负责人、核心交付物和验收条件（30分钟）
  4. 识别各阶段阻塞项和依赖关系，标注风险等级（低/中/高）及应对措施（25分钟）
  5. 输出里程碑甘特图或时间轴，在团队内同步宣导（20分钟）
- **完成标准**：所有阶段有明确的交付物、责任人和截止日期，风险项有应对方案，团队全员知晓

## 模板3：会议效率提升
- **适用场景**：提升日常会议产出，避免"开了等于没开"
- **核心步骤**：
  1. 会前24小时发出议程：列出议题、目标（讨论/决策/同步）、每个议题的时长上限（15分钟）
  2. 会前要求参会者提前阅读材料，在共享文档中异步留言提问（无需单独计时，融入会前流程）
  3. 会议中控时：每个议题到点提醒，超时议题移到"停车场"会后处理（会议期间同步执行）
  4. 会议结束时口头确认3项：决议内容、行动项责任人、截止日期（5分钟）
  5. 会后2小时内发出纪要，包含决议和行动项，抄送相关人员（10分钟）
- **完成标准**：会议有明确产出的决议和行动项，纪要在规定时间内发出，下次会议先回顾完成率

## 模板4：汇报材料准备
- **适用场景**：向上级或管理层做阶段性工作汇报/述职，需要PPT或文档材料
- **核心步骤**：
  1. 明确汇报对象、汇报目的和时间限制（决策汇报 vs 同步汇报？10分钟 or 30分钟？）（10分钟）
  2. 梳理核心数据：关键指标变化、同比/环比对比、异常点说明（30分钟）
  3. 搭建汇报骨架：背景→核心成果→数据支撑→问题与反思→下阶段计划（20分钟）
  4. 填充内容并精炼：每页只传达一个核心观点，数据用图表呈现，文字精简（40分钟）
  5. 预演一遍，调整语言节奏和逻辑顺序，准备预设问题的应答（20分钟）
- **完成标准**：汇报主线清晰、数据有据可查、能在规定时间内讲完、对可能提问有准备

## 模板5：跨部门协作推进
- **适用场景**：推进需要多部门配合的项目，解决"谁也不愿牵头"的协作难题
- **核心步骤**：
  1. 梳理协作需求：明确需要哪些部门、各自的角色和期望产出（20分钟）
  2. 起草协作方案，明确RACI矩阵（谁负责/谁批准/咨询谁/告知谁）（30分钟）
  3. 与各部门关键人一对一沟通，提前对齐诉求、化解潜在分歧（视部门数量，每部门15分钟）
  4. 召开启动对齐会：确认里程碑、交付节奏、沟通机制（邮件群/周会/群聊）（30分钟）
  5. 建立协作看板（如飞书多维表格/Notion），所有人可见进度，每周同步一次阻塞项（15分钟）
- **完成标准**：RACI矩阵经各方确认，协作看板运转正常，每周有进度同步，阻塞项48小时内响应
