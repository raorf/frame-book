# 学习模板

## 模板1：考研冲刺计划
- **适用场景**：考前2—4个月高强度备考，需要科学分配各科时间、保持节奏
- **核心步骤**：
  1. 梳理考试科目和分值权重，按"高分占比优先 + 弱科补强"原则分配每周科目时间（30分钟）
  2. 制定每日作息表：上午主攻弱项（3小时/天）、下午强项巩固（2小时/天）、晚上复盘+真题练习（2小时/天）（25分钟）
  3. 按科目设置3轮复习节奏——第一轮全覆盖（4周）、第二轮重难点突破（3周）、第三轮模拟冲刺（3周）（20分钟）
  4. 每周末安排1次全真模考，严格计时，考后分析错题类型并调整下周计划（模考3小时 + 分析1小时）
  5. 每两周做一次进展评估，根据模考分数趋势动态调整各科时间配比（15分钟）
- **完成标准**：每日作息可执行、模考分数呈上升趋势、薄弱科目有明显提升、考前完成至少8次全真模考

## 模板2：考试复习清单
- **适用场景**：期末考试、证书考试等中短期复习，基于间隔重复原理系统推进
- **核心步骤**：
  1. 列出全部考点/章节清单，逐项标注掌握程度（熟悉/模糊/陌生）（25分钟）
  2. 将"模糊"和"陌生"项按关联性分组，制定每日攻克清单（每天不超过3个新知识点）（15分钟）
  3. 调用间隔重复节奏：新学内容当天复习、次日复习、3天后复习、7天后复习、14天后复习（5分钟/每次复习）
  4. 每个知识点用费曼技巧自检：用白纸复述一遍，能讲清楚才算真正掌握（10分钟/知识点）
  5. 考前一周集中刷错题本，将错题按错误类型分类（概念不清/计算失误/审题偏差），针对性补漏（每天60分钟）
- **完成标准**：所有考点至少经历一次完整的间隔重复循环，错题本清零率>80%，自检通过率>90%

## 模板3：技能学习路径
- **适用场景**：从零开始学习一项技术技能（编程语言/数据分析/设计工具等），建立系统化的学习路线
- **核心步骤**：
  1. 确定技能目标和应用场景（学到"能做一个完整项目"而非"看完一本书"），调研行业常用技术栈和推荐学习资源（30分钟）
  2. 拆解技能树为3—5个能力模块，每个模块设置一个可展示的小项目作为验收标准（25分钟）
  3. 第一模块先跑通"最小闭环"：安装环境→运行Hello World→理解基本概念→完成练习题（每个模块2—5天，每天2小时）
  4. 每完成一个模块输出一篇学习笔记，记录踩坑点和关键理解，发布到博客或内部知识库（每篇40分钟）
  5. 学完全部模块后，做一个综合项目串联所学（如用爬虫+分析+可视化完成一个数据分析报告），放入作品集（项目周期3—7天）
- **完成标准**：每个模块有可运行的小项目，综合项目完成后能独立复现，作品集至少有3件成果

## 模板4：精读笔记法
- **适用场景**：深度阅读专业书籍/经典著作/技术文档，从"读完就忘"到"读完能用"
- **核心步骤**：
  1. 预览全书：翻目录、读序言、扫标题，建立整体知识地图，标注重点章节（10分钟）
  2. 逐章精读并做分层笔记——第一层：核心论点（一句话概括），第二层：关键论据和案例，第三层：自己的思考和联想（每章30—40分钟）
  3. 每读完一章，用5分钟写50字以内的章节小结，提炼一个可迁移的"行动启发"（5分钟）
  4. 全书读完后，绘制知识结构图（思维导图），标注各章节间的逻辑关联（30分钟）
  5. 将行动启发整理为待办清单，挑选1—3条在未来两周内实践，记录实践反馈（15分钟）
- **完成标准**：有完整的知识结构图，至少有3条启发进入实践阶段，能用自己的话向他人讲清楚这本书在说什么

## 模板5：知识输出计划
- **适用场景**：将学习成果转化为文章、教程或分享内容，以输出倒逼输入，巩固知识体系
- **核心步骤**：
  1. 盘点近期所学内容，从中筛选3—5个有分享价值的主题，按"对他人有用程度"排序（15分钟）
  2. 为每个主题写一句话定位：这篇文章给谁看？解决什么问题？读者看完能带走什么？（10分钟/主题）
  3. 按照"问题引入→核心方法→实操步骤→踩坑指南→总结延伸"的结构草拟大纲（20分钟/篇）
  4. 先写再改：初稿不求完美，一次性写完不中断；次日冷静期后修改逻辑漏洞和表达（初稿45分钟 + 修改30分钟）
  5. 发布后收集反馈，记录读者提问，作为下一篇内容的选题来源（持续进行）
- **完成标准**：每月至少产出2篇完整文章，每篇有明确的目标读者和可复用价值，读者反馈有正向互动
