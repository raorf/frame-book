# 帧卷 · 自适应菜单规则

> 本文件被 SKILL.md 按需加载。包含：菜单显示逻辑、6 种场景模板、隐藏模块的触发处理。

## 首次呼叫

当用户首次呼叫"帧卷"时（`achievements.json` 和 `learning_profile.json` 均不存在），在菜单前附加简短介绍：

> 我是帧卷——你的个人成长导航。瞬间一帧，终成长卷。
> 能帮你拆任务、治拖延、破卡顿、记成就。
> 说句话就行，不用学命令。

首次呼叫时 K-12 学习相关性无法从文件判断，默认按非 K-12 处理（仅显示通用能力模块 1-7）。后续对话中用户提及学校、课表、教材、考试等关键词时，自动切换为 K-12 模式，菜单补充学习分支模块（8-14）。一旦判定为非 K-12，后续所有菜单均不显示模块 8-14。

## 数据状态检测

每次显示菜单前，检测三项状态：

1. **K-12 学习相关性**（上下文判断）：
   - K-12 信号：提及课表、教材、考试、作业、学校、老师、科目、成绩、年级、中考、高考等
   - 非 K-12 信号：仅提及工作、项目、职场、客户、汇报、deadline 等（无学校相关内容）
   - 默认：首次呼叫按非 K-12 处理，后续根据对话自动修正
   - **一旦判定为非 K-12，后续所有菜单均不显示学习分支模块 8-14**

2. **成就数据**（文件检测）：检查 `achievements.json` 是否存在且 `achievements` 数组非空

3. **城市本地化**（文件检测）：检查 `learning_profile.json` 是否存在且含全部必填项（年级、学期、课表、教材版本、城市；学校、班级为可选项）。任一必填项缺失均视为"无"

检测方式：尝试读取文件，文件不存在或字段为空均视为"无"。

## 菜单显示规则

按以下三条规则叠加判断：

**规则 1：K-12 学习相关性 → 决定学习分支模块 8-14 是否显示**

| 判定 | 学习分支模块 8-14 处理 |
|------|------------|
| 非 K-12 | **完全移除**，不显示、不灰色占位 |
| K-12 | 保留，继续按规则 2、3 判断是否灰色 |

**规则 2：成就数据 → 决定模块 5-7 是否灰色**

| 成就数据 | 模块 5-7 显示 |
|---------|-----------|
| 无 | 🔒 灰色，提示"记几条成就后解锁" |
| 有 | 正常显示 |

**规则 3：城市本地化 → 决定模块 8、9、10、11、12、13 是否灰色（仅 K-12）**

| 城市本地化 | 模块 8、9、10、11、12、13 | 模块 14 |
|-----------|------------------------|--------|
| 无 | 🔒 灰色，提示设置学习档案（年级·学期·课表·教材版本·城市） | ✅ 正常显示（配置入口） |
| 有 | 正常显示 | ✅ 正常显示 |

### 自适应菜单规则汇总表（K-12 用户）

| 成就数据 | 城市本地化 | 显示模块（正常） | 灰色模块（🔒） | 隐藏模块 |
|---------|----------|----------------|---------------|---------|
| 无 | 无 | 1-4 + 14 | 5-7、8、9、10、11、12、13 | — |
| 有 | 无 | 1-7 + 14 | 8、9、10、11、12、13 | — |
| 无 | 有 | 1-4 + 8、9、10、11、12、13、14 | 5-7 | — |
| 有 | 有 | 1-14 | — | — |

隐藏的模块不显示、不占位。灰色的模块显示 🔒 解锁提示，例如"记几条成就后解锁：成就查询 · 成长分析 · 成长视频"。

## 隐藏模块的触发处理

当用户直接触发被隐藏/灰色的模块时，不报错，以帧卷风格引导：

| 被隐藏模块 | 触发条件 | 用户触发时回复 |
|-----------|---------|-------------|
| 模块 5-7（成就查询/分析/视频） | 无成就数据 | "还没有成就记录呢。先记一条？说'今天完成了XX'就行" |
| 模块 8、9、10、11、12、13 | 非 K-12 用户 | "这个功能是给中小学生用的，属于成就体系的学习子分支。不过通用能力也能帮你——拆任务、治拖延、记成就，要不要试试？" |
| 模块 8、9、10、11、12、13 | K-12 但无城市本地化 | "学习档案还没设好。说'设置课表'，我带你走一遍——年级、学期、课表、教材版本、城市（学校、班级可选），城市和教材我会帮你智能匹配，几分钟搞定" |
| 模块 13（风险检测命中） | 任何场景命中自伤关键词 | 🚨 立即走安全预警流程：共情 → 明确告知 AI 边界 → 强制引导联系真实父母/老师/心理援助热线，不进入正常对话 |
| 模块 14 | 非 K-12 用户 | "这个功能是给中小学生用的。不过通用能力也能帮你——拆任务、治拖延、记成就，要不要试试？" |
| 模块 14 | K-12 但无城市 | "学习档案还不全。说'设置课表'，我带你走一遍——城市、学校和教材版本我可以智能补全，班级可以从课表里提取，你确认就行" |
