# 生活模板

## 模板1：周计划模板
- **适用场景**：每周初规划本周核心任务与时间安排，确保要事优先、时间合理分配
- **核心步骤**：
  1. 清空大脑：列出本周所有待办事项，不分类不筛选，全部写下来 (预估10分钟)
  2. 优先级矩阵分类：将事项按"重要-紧急"四象限归类，圈出3件重要不紧急的"大石头"任务 (预估15分钟)
  3. 时间块分配：将每天划分为2-4个时间块，把3件大石头任务安排在精力高峰时段，留出20%缓冲 (预估15分钟)
  4. 批处理琐事：将邮件、消息、行政类事项集中在每天1-2个固定时段批量处理 (预估5分钟)
  5. 设定每周锚点：确定1个必做仪式（如周五复盘），写进日历不可被覆盖 (预估5分钟)
- **完成标准**：产出一份本周时间块日程表，标注3件核心任务、每日时间块分配和1个周锚点仪式

## 模板2：月度复盘流程
- **适用场景**：月末回顾本月目标达成情况，提炼经验教训，制定下月调整方向
- **核心步骤**：
  1. 数据回顾：对照月初目标清单，逐项标注完成/部分完成/未完成，记录实际完成率 (预估15分钟)
  2. 成就盘点：列出本月3个最有成就感的成果，分析成功背后的关键动作和有利条件 (预估15分钟)
  3. 教训提炼：列出2-3个未达预期的事项，用"5问法"追问根因，区分能力问题、精力问题还是策略问题 (预估20分钟)
  4. 调整决策：基于复盘结论，明确下月"继续做、停止做、开始做"各2项 (预估10分钟)
  5. 精简下月目标：从调整清单中选出不超过3个核心目标，写入下月计划 (预估10分钟)
- **完成标准**：产出一份月度复盘文档，包含完成率统计、成就清单、根因分析和下月3个核心目标

## 模板3：年度目标拆解
- **适用场景**：年初设定年度大目标后，需要拆解为可执行的季度里程碑，避免目标悬空
- **核心步骤**：
  1. 目标校验：用SMART原则检验年度目标是否具体、可衡量、可实现、相关、有时限，必要时改写 (预估15分钟)
  2. 季度里程碑设计：将年度目标拆为4个季度里程碑，每个里程碑应是可验证的阶段性成果 (预估20分钟)
  3. Q1行动计划：将本季度里程碑进一步拆解为3-5个关键行动，每个行动明确负责人、截止日和验收标准 (预估15分钟)
  4. 资源与障碍预判：列出完成Q1目标所需资源（时间、金钱、技能、人脉），预判2个主要障碍及应对预案 (预估10分钟)
  5. 设定检查节奏：确定每月1次进度自查、每季度1次正式复盘的检查机制，写入日历 (预估5分钟)
- **完成标准**：产出年度目标拆解表，包含4个季度里程碑、Q1关键行动计划、资源清单和检查节奏安排

## 模板4：决策分析框架
- **适用场景**：面临重要人生或工作决策时，系统分析利弊与风险，避免冲动或回避
- **核心步骤**：
  1. 决策陈述：用一句话明确"我要在什么时间前、在哪些选项中、做出什么决定"，写出决策标准 (预估10分钟)
  2. 利弊分析：为每个选项列出5条利和5条弊，按影响程度1-5分打分，计算净分 (预估20分钟)
  3. 风险评估：识别每个选项的3个主要风险，按"发生概率×影响程度"评估，标注是否可承受及应对方案 (预估15分钟)
  4. 价值观校验：对照个人核心价值观排序，检查哪个选项更契合长期价值取向 (预估10分钟)
  5. 反悔测试：想象10个月后回头看，哪个选择更不容易后悔？写下一句决策结论和理由 (预估5分钟)
- **完成标准**：产出一份决策分析文档，包含各选项利弊评分表、风险评估表、价值观校验和最终决策结论

## 模板5：生活平衡轮
- **适用场景**：定期评估生活各维度的满意程度，识别失衡领域，制定改善计划
- **核心步骤**：
  1. 八维度自评：对事业、财务、健康、家庭、社交、成长、休闲、心灵8个维度，按1-10分打当前满意度 (预估15分钟)
  2. 绘制平衡轮：在雷达图上标注8个维度得分，连线形成现状轮廓，直观识别最低的2-3个维度 (预估5分钟)
  3. 差距分析：针对最低的2个维度，各写出"理想状态"和"当前状态"的具体描述，量化差距 (预估15分钟)
  4. 制定改善行动：为每个低分维度设计1个30天内可完成的改善行动，要求具体、低成本、有反馈 (预估15分钟)
  5. 设定重评节点：3个月后重新评分，记录变化趋势，调整改善重点 (预估5分钟)
- **完成标准**：产出生活平衡轮评分图、2个重点维度的差距分析和30天改善行动计划，标注下次重评日期
