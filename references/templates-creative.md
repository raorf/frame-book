# 创作模板

## 模板1：写作破冰
- **适用场景**：面对空白文档无从下笔、写作卡顿、思绪混乱时，通过自由书写与提示词技巧快速进入写作状态
- **核心步骤**：
  1. 设定计时器，围绕主题进行10分钟不间断自由书写，不停笔、不修改、不评判 (预估10分钟)
  2. 从自由书写内容中标记3个有价值的切入点或金句，挑选其中1个作为核心方向 (预估5分钟)
  3. 用"谁-什么-为什么-怎么做"四问法快速搭建文章骨架，列出3-5个关键段落要点 (预估8分钟)
  4. 基于骨架完成初稿第一段，设定最小目标（如200字），先完成再完美 (预估7分钟)
- **完成标准**：产出一篇有明确主题方向和开头段落的初稿雏形，字数不少于200字，具备可继续展开的结构骨架

## 模板2：文案创作流程
- **适用场景**：需要从需求简报出发，完成品牌文案、推广文案、社媒文案等商业内容创作
- **核心步骤**：
  1. 拆解需求简报，明确目标受众画像、核心卖点、调性要求和投放渠道特征 (预估15分钟)
  2. 提炼核心信息层级：1个主诉求 + 3个支撑点 + 1个行动召唤，形成文案逻辑主线 (预估10分钟)
  3. 撰写初稿，先写3个不同角度的标题备选，再完成正文，注重开头3秒抓取注意力 (预估25分钟)
  4. 朗读校验节奏感，检查信息密度，删减冗余表述，确保每句话都服务于核心诉求 (预估15分钟)
  5. 产出2-3个版本供选择，附上各版本适用场景说明和推荐理由 (预估10分钟)
- **完成标准**：交付2-3个完整文案版本，每个版本包含标题、正文和行动召唤，附带选版建议

## 模板3：创意激发方案
- **适用场景**：需要产出新点子、突破思维定式、为项目寻找创意方向时使用
- **核心步骤**：
  1. 明确创意目标，用一句话描述"我想解决什么问题/创造什么价值"，设定产出数量目标（至少20个想法） (预估5分钟)
  2. 中心词发散思维导图：以核心主题为中心，向外发散5个方向，每个方向再延伸3个子方向 (预估15分钟)
  3. 强制联想练习：随机选取3个不相关词汇，分别与主题做"如果…会怎样"的跨界联想，记录所有火花 (预估10分钟)
  4. SCAMPER法迭代——对现有想法依次用替代、组合、调整、修改、其他用途、消除、重组7个角度催化新变体 (预估15分钟)
  5. 用"新颖度×可行性"二维矩阵筛选想法，选出Top 5进入下一步验证 (预估10分钟)
- **完成标准**：产出不少于20个原始创意点，筛选出5个高潜力方案，每个方案附一句话说明和可行性初判

## 模板4：内容系列规划
- **适用场景**：需要策划一个系列内容（如专栏、连载、系列视频），建立主题框架和发布节奏
- **核心步骤**：
  1. 定义系列定位：明确目标受众、核心价值主张、系列总篇幅和预期完播/阅读时长 (预估10分钟)
  2. 搭建主题树：确定1个总主题下3-5个子主题，每个子主题规划2-3期内容，形成内容矩阵 (预估20分钟)
  3. 为每期内容填写一页纸简介：标题、核心观点、关键案例、内容形式、预估篇幅 (预估25分钟)
  4. 制定发布排期表：标注每期发布日期、依赖关系、素材准备节点，预留1-2期缓冲库存 (预估15分钟)
  5. 设计系列视觉标识和开头/结尾模板，确保系列内容的统一辨识度 (预估15分钟)
- **完成标准**：产出完整的系列内容规划文档，包含主题树、分期简介表、发布排期表和视觉规范说明

## 模板5：改稿优化清单
- **适用场景**：初稿完成后，需要从结构、语气、清晰度等维度系统性打磨提升文章质量
- **核心步骤**：
  1. 结构诊断：通读全文，画出当前逻辑流向图，检查段落顺序是否层层递进，标记逻辑断层和冗余段落 (预估15分钟)
  2. 开头结尾强化：重写开头确保前3句能抓住读者，重写结尾确保有回扣主题和留有余味 (预估15分钟)
  3. 语气一致性校准：统一全文人称视角和情感基调，删除风格跳脱的段落，增强作者声音辨识度 (预估10分钟)
  4. 清晰度优化：对每个长句做"能否更短"测试，对抽象表述补充具体案例或数据，消除模糊指代 (预估20分钟)
  5. 终稿校对：朗读全文检查节奏，逐句检查错别字、标点和格式，确认符合发布规范 (预估10分钟)
- **完成标准**：产出经过五轮优化的终稿，附带一份改动记录说明主要调整点及调整理由
